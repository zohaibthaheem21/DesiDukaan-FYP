# DesiDukaan - Data-Driven E-Commerce Platform

DesiDukaan is a multi-vendor e-commerce platform designed for local artisans and vendors to showcase and sell products to online customers, featuring bilingual support in English and Sindhi.

The platform includes data science and analytics features such as product recommendations, customer review sentiment analysis, sales forecasting, and customer behavior segmentation.

## Key Features

- **Multi-Vendor Marketplace**: Customer product browsing, vendor registration with document verification, and admin shop approval workflows.
- **Bilingual Support**: Instant language switching between English and Sindhi.
- **Product Recommendation Engine**: Collaborative filtering system to recommend personalized products to buyers.
- **Review Sentiment Analysis**: Natural Language Processing (NLP) to analyze customer review feedback.
- **Business Intelligence Dashboards**: Vendor analytics for sales forecasting and customer behavior segmentation.
- **Dataset Export**: Export e-commerce data to CSV format for exploratory data analysis.

## Installation & Setup

1. Copy the project folder to your local server directory (e.g., XAMPP `htdocs`).
2. Start Apache and MySQL in XAMPP.
3. Open `http://localhost/DesiDukaan/reset_database.php` or `setup_data_science_features.php` in your browser to initialize the database and analytics features.
4. Access the application at `http://localhost/DesiDukaan`.
