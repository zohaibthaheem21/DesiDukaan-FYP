🏪 DesiDukaan Setup Instructions

Step 1: Start XAMPP Services

Make sure the following XAMPP services are running:

  • ✅ Apache
  • ✅ MySQL

Step 2: Setup Database

Choose one of the following methods:

Method A: Using phpMyAdmin (Recommended)

  1. Open phpMyAdmin
  2. Click on "Import" tab
  3. Choose file: database/setup_clean.sql
  4. Click "Go" to import

Method B: Manual SQL Execution

  1. Open phpMyAdmin
  2. Click on "SQL" tab
  3. Copy and paste the contents of database/setup_clean.sql
  4. Click "Go" to execute

Step 3: Create Upload Directories

Make sure these directories exist and are writable:

  • uploads/
  • uploads/cnic/
  • uploads/logos/
  • uploads/products/

Step 4: Access the Application

Once the database is set up, you can access the application:

🚀 Launch DesiDukaan

🔑 Admin Login Credentials

Email: admin@desidukaan.com

Password: password

⚠️ Important Security Note

Change the admin password immediately after first login!

Delete this setup file and setup.php after installation.

🧪 Testing the Application

Test Customer Registration:

  1. Go to the application
  2. Click "Register as Customer"
  3. Fill in the form and submit
  4. Login with your credentials

Test Seller Registration:

  1. Click "Register as Seller"
  2. Fill in all required fields including CNIC and mobile
  3. Create your shop with required documents
  4. Wait for admin approval

Test Admin Panel:

  1. Login with admin credentials
  2. Review pending shop requests
  3. Approve or reject shops

📞 Support

If you encounter any issues:

  1. Check that XAMPP services are running
  2. Verify database connection in config/database.php
  3. Check PHP error logs
  4. Ensure upload directories have proper permissions
